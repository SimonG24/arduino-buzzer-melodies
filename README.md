  # Arduino Buzzer Melodies
  
  A beginner Arduino project using a passive buzzer and push button to play recognisable melodies on command.
  
  ## Components Used
  - Arduino UNO R4 WiFi
  - Passive buzzer
  - Tactile push button
  - Breadboard and jumper wires
  - Resistors
  
   ## What It Does
  Press the button and the buzzer plays a melody. Release and it stops. Melodies include Mario theme, Peppa Pig and Bluey themes      built using the tone() function to control sound frequency.
  
  ## What I Learned
  - How to use tone() and noTone() functions
  - Controlling sound frequency and duration in code
  - Digital input using a push button with INPUT_PULLUP
  - Conditional logic — if button pressed, play melody
